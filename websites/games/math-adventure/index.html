How to Play

Welcome to Math Adventure! Solve math problems to earn coins and buy prizes!

How It Works:

  1. Look at the math problem and the picture clues
  2. Tap the correct answer
  3. Earn coins for correct answers!
  4. Build a streak for bonus coins
  5. Spend coins in the Store on real prizes
  6. Earn Badges for special achievements

Bonus Rounds

Every 10th problem is a bonus round worth double coins!

Coins Earned:

Addition / Subtraction:

  • 1st try: 5 coins
  • 2nd try: 3 coins
  • 3rd try: 1 coin
  • Miss (all wrong): 0 coins

Multiplication / Division:

  • 1st try: 7 coins
  • 2nd try: 5 coins
  • 3rd try: 3 coins
  • Miss (all wrong): 0 coins

Bonuses:

  • Streak bonus: +1 per 5 streak
  • Bonus round: double coins!
